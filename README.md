# 다올105 배포 퍼널 콘솔

강사가 준 **블로그 초안 + 사진**만 넣으면 → **랜딩·블로그·인스타·유튜브 4종 + 카드뉴스**를 자동 생성하고, 직접/AI 수정 후 **원클릭 배포**까지 하는 인포데스크 도구.

## 파일
- `index.html` — **콘솔 웹앱(본체)**. 깃허브 페이지에 올려 URL로 씀. 단일 파일.
- `2단계_실제API_자동발행_가이드.md` — 인스타/유튜브 실제 자동발행 계정·앱 세팅 순서(정직한 한계 포함).
- `backend/worker.js`, `backend/wrangler.toml` — 인스타/유튜브 자동발행용 Cloudflare Worker 스캐폴드.

## 1단계 — 지금 바로 사용 (완성)
1. `index.html`을 깃허브 레포에 올리고 Pages 켜기 → 콘솔 URL 확보.
2. 콘솔 ⚙설정: **Anthropic API 키**, **깃허브 토큰(레포 contents:write)**, 학습 노트.
3. 강사 자료 붙여넣기 + 사진 업로드 → **🪄 4종 자동 생성**.
4. 탭에서 직접 수정 or "AI 수정" → 카드뉴스 PNG 다운로드.
5. **✅ 수정완료 배포**(랜딩=재확인 팝업 후 깃허브 원클릭 배포 / 나머지=발행키트 복붙).
6. **강사 회신 메시지** 복사해서 전달.

동작 규칙(브레인): 설득구조(문제→해결) · 정직성(성과·수치 조작 금지, 개념모델 라벨, 단정 완화) · 네이버 SEO 2026 · 카드뉴스 남색+골드 · 해시태그 20 · 컴플라이언스.

## 2단계 — 실제 자동발행 (계정 세팅 후)
`2단계_실제API_자동발행_가이드.md` 참고. **인스타 카드뉴스 자동발행 + 유튜브 영상 자동업로드**가 가능(앱심사·OAuth 필요, 몇 주). **네이버 블로그·유튜브 커뮤니티 글은 API가 없어 항상 발행키트.**

## 계속 학습
⚙설정 → **학습 노트**에 원칙을 쌓으면 매 생성에 자동 반영. (예: 표지 고정문구, 변형 정의, 강사 표기 규칙)
